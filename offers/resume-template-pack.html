Why Most Resumes Get Rejected Before a Human Sees Them

File Formats — Which to Use When

Every template comes in both .docx and PDF format. Here's when to use each:

When to submit .docx (Word format)

Use .docx when: The job posting says "submit as .doc or .docx," the ATS is a legacy system, or you're applying to a role where the recruiter might need to edit or annotate your resume.

How to prepare: Open the .docx template in Word or Google Docs. Edit. Save as .docx with a professional filename: Firstname_Lastname_Resume.docx.

When to submit PDF

Use PDF when: The job posting doesn't specify a format, you're applying to modern companies (tech, startups, creative), or you want to guarantee the formatting stays exactly as designed.

How to prepare: Export from Word or Google Docs as a text-based PDF. Not a scanned PDF or an image-based PDF — those fail ATS parsing.

Both formats — the safest strategy

Best practice: Have both versions ready. When a job posting is ambiguous, submit .docx. When it specifies PDF, submit PDF. Never submit both at the same time unless the posting asks for both.

How to Export From Google Docs

  1. Open the .docx template in Google Drive
  2. Click File → Download → Microsoft Word (.docx) for Word format
  3. Click File → Download → PDF Document (.pdf) for PDF format
  4. Rename the file to Firstname_Lastname_Resume

How to Customize Each Template

All 10 templates are fully editable. Here's how to make each one your own.

Colors

Each template uses a subtle accent color (usually a dark blue, teal, or slate). To change it:

  • In Word: Format → Style → Change color scheme
  • In Google Docs: Right-click on colored text → Change text color
  • Keep it dark and professional — avoid bright colors unless you're in a creative field

Fonts

Each template uses ATS-safe fonts. If you change the font, stay within the safe list:

  • Safe fonts: Arial, Calibri, Helvetica, Georgia, Times New Roman, Garamond
  • Avoid: Comic Sans, Papyrus, Impact, and anything decorative

Sections

Add or remove sections to fit your experience:

  • Add: Certifications, Languages, Projects, Volunteer Work, Publications
  • Remove: Any section that doesn't have content, or that isn't relevant to the job

Length

The templates are set up for one page. If your experience requires two pages:

  • Delete any sections you don't need
  • Tighten your bullet points (one line instead of two)
  • Reduce margins slightly (but not below 0.5 inch)
  • Reduce font size to 10pt for body text (but not below)

Filename

Always use a professional filename: Firstname_Lastname_Resume.pdf

Never use: "resume_final_v3_updated.pdf" or "my resume (1).pdf"
